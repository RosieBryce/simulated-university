# Document Naming Convention

Information Governance Group, 22 March 1051. Version 1.0. Applies to all documents saved to the Hub.

## The rule

Name documents so that someone who has never seen them can tell, from the name alone, what they are, when they are from, and which version they are looking at.

The standard form is:

**YYYY-MM-DD_Topic-In-Title-Case_vNN.ext**

For example:

- `1053-02-05_Senate-Minutes_v01.docx`
- `1052-10-17_Faculty-NSS-Deep-Dive_v01.docx`
- `1053-01-20_Placement-Allocation-1052-53_v03.xlsx`

## The parts

**Date.** The date the document relates to (the meeting date, the reporting date, the date of issue), not the date you saved it. Year first, four digits, then month and day with leading zeros. This makes documents sort in date order in any folder.

**Topic.** Three to six words in Title Case, joined with hyphens. Use the words a colleague would search for. Avoid abbreviations unless they are universal in the University (NSS, DPIA, FtP).

**Version.** Two digits with a leading zero: v01, v02. Increment the version each time a document is circulated. Do not use "final", "FINAL", "latest", "new", "amended", "USE THIS" or your own name. A document is never final; it has a version.

**Extension.** Leave it alone.

## What not to do

| Do not | Because |
|---|---|
| `Minutes.docx` | Which meeting? When? |
| `Minutes FINAL FINAL (use this one).docx` | Three people will each believe a different file is the final one |
| `Copy of Placement Allocation (1).xlsx` | A copy is a new version or it is a duplicate to be deleted |
| `Deans thing v3.docx` | Whose thing? What thing? |
| `14.03.53 memo.docx`, `14032053 memo.docx`, `March memo.docx` | Three date formats in one folder cannot be sorted |
| Dates in the name that differ from the date in the document | One of them is wrong and nobody knows which |

## Versions and copies

Save one document and version it. If you must keep a superseded version, move it to a folder named `Superseded`, not `Old`, `Archive` or `Misc`. Do not keep superseded versions next to the current one.

A copy made for a different purpose (for example an extract for another committee) is a new document with its own name, not "Copy of".

## Folders

Folder names follow the same spirit: meaningful words, no personal names, no `New folder`, no `To sort`. A folder called `Misc` is a folder nobody will ever open again. If a folder is more than five levels deep, the structure is wrong.

## Exceptions

Corporate templates keep their standard names. Documents generated by systems (extracts, exports) keep the system's name. Email attachments should be renamed to the convention when saved to the Hub.

## Enforcement

None, beyond this document and the goodwill of colleagues. Planning and Insight follow it. Governance and Secretariat follow it. The Information Governance Group asks that teams migrating material from legacy drives rename it on arrival rather than afterwards, since afterwards never comes.
