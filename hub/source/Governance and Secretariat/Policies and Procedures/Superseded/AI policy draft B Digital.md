# Generative AI: Guidance for Staff (Draft B)

Digital Services redraft, 14 October 1052, responding to Information Governance draft 0.1. Not approved.

## 1. Purpose

1.1 Staff are already using generative AI tools. A policy that prohibits what is already happening will be ignored and will push use out of sight. This guidance aims to make use visible and sensible.

## 2. Principles

2.1 You are responsible for what you produce, however you produce it.

2.2 Check outputs. Tools make things up.

2.3 Use common sense about sensitive material.

## 3. Guidance

3.1 Staff may use any generative AI tool for any University work provided they do not enter special category personal data (health, ethnicity, and so on) into a tool that is not provided by the University.

3.2 Staff should prefer the University-provided tool, Cloudi, once available, because it has contractual protections.

3.3 Staff should be transparent about significant use.

3.4 Line managers may set local rules.

## 4. Support

4.1 Digital Services will publish a list of recommended tools and configuration guidance.
